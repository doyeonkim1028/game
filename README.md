# 나의 투자성향 진단 게임

문진표 형식의 문항에 답하면 위험회피도를 측정해 5가지 투자성향 중 하나로 진단하고, 추천 자산 비율과 실제 상품(ETF·예금) 기반 수익률을 보여주는 웹 게임입니다. 테마는 "투자성향 클리닉"입니다.

- 게임 링크: https://claude.ai/artifact/Gm8u9gpsBTBxYbmpUqaV1p (링크가 있는 누구나 볼 수 있음)
- 실제 상품 시세(KODEX 200, SPY, KODEX 국고채3년)는 야후 파이낸스에서 매일 한 번 받아와 반영합니다.

> 게임용으로 단순화한 진단이며, 실제 투자 권유나 공식 투자성향 진단이 아닙니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (HTML·CSS·JavaScript 한 파일). 캐릭터 이미지와 시세 데이터도 안에 들어 있음 |
| `collect_market.py` | 야후 파이낸스에서 KODEX 200·SPY·KODEX 국고채3년과 원/달러 환율을 받아와 저장하고 `index.html`에 넣음 |
| `publish_check.py` | 자동 게시 전 안전 확인 (시세 데이터만 바뀌었는지 검사) |
| `market_data.csv` | 매일 하루치씩 쌓이는 시세 기록 (엑셀로 열기 가능) |
| `market_data.json` | 최신 시세 요약 사본. 게임은 이 파일이 아니라 `index.html` 안의 데이터를 읽음 |
| `.published/index.html` | 마지막으로 게시한 버전. `publish_check.py`의 비교 기준 |
| `agent.md` | 초기 기획 메모 (주식 차트 테마 시절 내용이라 지금 디자인과 다름) |

## 게임 흐름

1. **접수 (시작화면)**: 환자명(닉네임, 최대 10자) 입력 후 "접수하기" 또는 Enter
2. **문진표**: 11문항 (기본 정보 · 투자 병력 · 반응 검사 · 멘탈 검진). 선택하면 자동으로 다음 문항, "← 이전 문항"으로 수정 가능
3. **진단 중**: 짧은 로딩 연출
4. **처방전 (결과화면)**: 요약 카드 + 탭 4개(소견·처방 / 자산 비율 / 시장 바이탈 / 2020 시뮬레이션)
   1. 진단명: 유형 캐릭터, 한 줄 설명, 진단완료 도장
   2. 위험 게이지, 검사 수치(위험회피도·위험감수도)
   3. 소견과 처방 상품
   4. 조제 내역: 추천 자산 비율 도넛 그래프
   5. 오늘의 시장 바이탈: 세 ETF의 종가(원)와 등락률, 정기예금 금리, "3개월 전에 투자했다면?" 수익률
   6. 임상 기록: 2020년 코로나 폭락장 시뮬레이션
   7. 문진 기록(답변별 점수), 처방전 복사, 다시 접수하기

## 화면 배치

| 화면 | 휴대폰 (600px 이하) | 태블릿 (601~999px) | 컴퓨터 (1000px 이상, 최대 1120px) |
|---|---|---|---|
| 접수 | 한 줄 | 한 줄 (최대 760px) | 왼쪽 소개·진료 과목 / 오른쪽 접수 폼, 스크롤 없이 한 화면 |
| 문진표 | 한 줄 | 한 줄 | 왼쪽 Ⅰ~Ⅳ 단계 체크리스트 / 오른쪽 질문, 키보드 숫자로 선택 |
| 처방전 | 캐릭터·유형·도장 → 탭(2×2), 복사·다시 접수 버튼 화면 하단 고정 | 요약 → 탭(한 줄) → 버튼 | 왼쪽 요약 카드(스크롤해도 고정) / 오른쪽 탭 |

그래프는 해당 탭을 처음 열 때 그립니다.

## 진단 방식

- 선택지는 1점부터 보기 수만큼 점수를 줍니다 (5지선다 1~5점, 4지선다 1~4점).
- 문항마다 0~1로 환산해 평균을 내고 × 100 한 값이 **위험감수도**, 100 − 위험감수도가 **위험회피도**입니다.
- 분류 체계는 금융투자협회 표준 투자자정보확인서의 5단계를 참고했습니다.

| 위험감수도 | 유형 | 캐릭터 | 예금 | 채권 | 국내주식 | 해외주식 |
|---|---|---|---|---|---|---|
| 0~20 | 안정형 | 거북이 | 80% | 20% | 0% | 0% |
| 21~40 | 안정추구형 | 다람쥐 | 50% | 35% | 5% | 10% |
| 41~60 | 위험중립형 | 진돗개 | 30% | 30% | 20% | 20% |
| 61~80 | 적극투자형 | 여우 | 15% | 20% | 30% | 35% |
| 81~100 | 공격투자형 | 독수리 | 5% | 10% | 40% | 45% |

### 자산별 실제 상품

| 자산 | 상품 | 야후 티커 | 고른 이유 |
|---|---|---|---|
| 예금 | 은행 정기예금 | (없음) | 한국은행 '금융기관 가중평균금리'의 예금은행 저축성수신금리(신규취급액)를 가입한 달 기준으로 고정 적용 |
| 채권 | KODEX 국고채3년 | `114260.KS` | 대표적인 한국 국채 ETF (2009년 상장) |
| 국내주식 | KODEX 200 | `069500.KS` | 코스피200을 추종하는 거래량 1위 국내 ETF |
| 해외주식 | SPY | `SPY` | 세계 최대 S&P 500 ETF. 원/달러 환율(`KRW=X`)을 곱해 원화로 환산 |

- 국내 상장 S&P 500 ETF(TIGER 미국S&P500 등)는 2020년 8월 이후 상장이라 코로나 시기를 계산할 수 없어서, 모든 기간을 같은 기준으로 맞추려고 SPY 원화 환산을 씁니다.
- ETF 수익률은 배당(분배금)을 반영한 수정주가로 계산합니다. 수수료·세금은 반영하지 않습니다.

**예금 금리 표** (`index.html`의 `DEPOSIT_RATES`, 자동 갱신 안 됨)

| 달 | 금리(연) | 출처 |
|---|---|---|
| 2020년 1월 | 1.54% | 한국은행 발표, [뉴데일리 2020.2.28](https://biz.newdaily.co.kr/site/data/html/2020/02/28/2020022800095.amp.html) |
| 2026년 8월 | 3.21% | 9월 값에서 전월 대비 +0.24%p를 빼서 계산 |
| 2026년 9월 | 3.45% | 한국은행 발표, [데일리환경 2026.11.3](https://www.dailyt.co.kr/newsView/dlt202611030003) |

한국은행이 새 달 금리를 발표하면 이 표에 한 줄 추가해야 합니다 (보통 다음 달 말 발표).

## 수익률 계산

**3개월 전에 투자했다면? (실제 상품)**
- 야후 파이낸스의 최근 3개월 첫 거래일 → 가장 최근 거래일까지 세 ETF의 수익률(배당 포함, 원화)을 구합니다.
- 예금은 가입한 달의 금리 × 경과 일수로 계산합니다 (중도해지 불이익은 무시).
- 유형별 비율로 1,000만 원을 나눠 투자했다고 계산합니다.

**2020년 코로나 폭락장 시뮬레이션**
- 2020년 1월 초 1,000만 원을 유형 비율로 투자했다고 가정하고 월별 자산을 계산합니다.
- 세 ETF의 2019년 12월 말 ~ 2020년 12월 말 실제 월말 값(배당 포함, SPY는 그날 환율로 원화 환산)을 씁니다.
- 예금은 2020년 1월 금리 연 1.54%로 고정합니다.

## 실제 상품 데이터: 매일 업데이트

게임 페이지는 보안상 외부 사이트에 직접 접속할 수 없습니다. 그래서 파이썬이 내 컴퓨터에서 시세를 받아 `index.html` 안에 넣고, 그 파일을 다시 게시하는 방식입니다.

```
야후 파이낸스 → 파이썬(가져오기) → JSON(중간다리) → JavaScript(계산·화면) → 게임 화면
```

**매일 오후 4시 30분 자동 작업** (Claude 앱의 예약 작업 "투자성향 게임 시세 매일 업데이트")
1. `collect_market.py` 실행: KODEX 200·SPY(원화 환산)·KODEX 국고채3년 일봉과 3개월 수익률을 받아 `market_data.csv`·`market_data.json`에 저장하고, `index.html`의 시세 데이터 블록을 바꿈
2. `publish_check.py` 실행: 마지막 게시본과 비교해 시세 데이터만 바뀌었는지 확인. 다른 내용도 바뀌었으면 게시하지 않고 알림
3. 게임 링크에 다시 게시하고, 기준 사본(`.published/index.html`)을 갱신
4. 종가, 등락률, 3개월 수익률, 수집 진행 상황을 요약해서 알림

- Claude 앱이 켜져 있을 때만 실행되고, 꺼져 있었다면 다음에 앱을 켤 때 실행됩니다.
- 첫 수집일부터 10거래일이 모이면 "수집 완료"로 표시됩니다 (주말·휴장일 제외).

## 직접 실행하기

Python 3.12 기준이며, 표준 라이브러리만 쓰므로 따로 설치할 패키지가 없습니다.

```bash
python collect_market.py
```

최신 시세를 받아 표로 보여주고 파일을 갱신합니다. 같은 날 여러 번 실행해도 중복 저장되지 않습니다. 이렇게 하면 내 컴퓨터 파일만 바뀌고, 링크에는 다음 자동 작업 때 반영됩니다.

```bash
python publish_check.py
```

시세 데이터만 바뀌었는지 확인합니다 (종료 코드 0: 데이터만 바뀜, 1: 다른 내용도 바뀜, 2: 오류).

## 주의할 점

- **`index.html`을 직접 고치면 자동 게시가 멈춥니다.** 고친 뒤 다시 게시하고 `python publish_check.py --save`로 기준 사본을 갱신해야 다음 날부터 자동 업데이트가 이어집니다.
- `index.html`의 `<!-- MARKET_DATA:START -->`부터 `<!-- MARKET_DATA:END -->`까지는 `collect_market.py`가 매번 덮어쓰므로 손으로 고치지 마세요.
- 이 컴퓨터에서는 Windows 보안 정책 때문에 pandas(그리고 이를 쓰는 yfinance)가 실행되지 않습니다. 그래서 `collect_market.py`는 야후 파이낸스 시세 주소에 직접 요청합니다.
- 숫자는 실시간이 아니라 수집 시각 기준입니다. SPY는 미국 장 시간 때문에 하루 전 날짜로 보일 수 있습니다.
- 예금 금리 표는 자동으로 바뀌지 않습니다. 매일 자동 작업이 월말쯤 갱신이 필요할 수 있다고 알려줍니다.
